# L4 Interprocedural SDG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Emit the L4 layer of canonical schema v2 — synthetic parameter vertices, `param_in`/`param_out` application edges, semantic `prov:["points-to"]` ddg, and (second PR) `summary` edges — behind `-a 4`.

**Architecture:** Two PRs. PR 1 (issue [#184](https://github.com/codellm-devkit/codeanalyzer-java/issues/184)): schema model additions; a **pure, deterministic vertex/edge builder** that derives formal/actual vertices and `param_in`/`param_out` from the L2-backfilled `body` call nodes (no engine risk); WALA per-method PDGs re-primed with **application-scoped mod/ref maps** for the semantic ddg; CLI `-a 4` + `--precision`. PR 2 (issue [#185](https://github.com/codellm-devkit/codeanalyzer-java/issues/185)): Tarjan SCC condensation + k-limited bottom-up summary fixpoint, emitting `summary` edges; Neo4j overlay of all three edge kinds.

**Construction choice (deviation from spec §9, output-identical):** the spec names WALA `SDG<InstanceKey>` as the engine for `param_*` edges. Those edges are structurally determined by the call graph alone — one `actual_in` per argument per resolved call site wired to the callee's `formal_in:i` — so this plan derives them **directly from the v2 model** (body `call` nodes with backfilled `callee` + callable parameter lists). Rationale: `WalaAnalysis` deliberately skips the global ModRef closure (OOM at 4 GB over a JDK-inclusive call graph — see `WalaAnalysis.emptyDefaultingMap` javadoc), WALA's full SDG re-opens exactly that risk, and the derived output is identical and byte-deterministic. WALA stays the engine for what genuinely needs points-to: the semantic ddg (Task 5). The WALA-SDG construction remains the recorded fallback if the derived edges ever prove insufficient (spec §16 risk-register style).

**Tech Stack:** Java 11+, JavaParser (existing L1/L3-ast), WALA 1.6.7 (`com.ibm.wala.ipa.slicer`/`ipa.modref` already on classpath — no dependency change), Lombok `@Data`, Gson `LOWER_CASE_WITH_UNDERSCORES`, JUnit 5, Gradle.

**Spec:** `docs/design/specs/schema-v2-l3-l4-design.md` (§5, §9, §10, §14, §16) + `docs/design/specs/l3-intraprocedural-dataflow-design.md` (D25–D29 constrain identity and monotonicity). Tracking: epic codellm-devkit/.github#42, children #184 (Tasks 1–7) and #185 (Tasks 8–10).

## Global Constraints

- **Additivity (D28):** L4 only adds — every L3 node/edge survives byte-identical; semantic ddg edges are *added to* `ddg`, never replace `prov:["ssa"]` ones. CI gate: `-a 3` payload ⊆ `-a 4` payload.
- **Flag gating:** nothing L4 runs below `-a 4`; `-a 1..3` timings and output unaffected.
- **Identity (D25 + keystone):** body-node local keys — `@formal_in:<i>`, `@formal_out` (callable-level synthetics), `<call-local>/actual_in:<i>`, `<call-local>/actual_out` (call-site children). `param_in`/`param_out` live on the **application** with **global-ordinal endpoints** (`<callable-id>@<local>`); `summary` lives on the **callable** with **local** endpoints. Global ordinal rule: local starting with `@` concatenates (`<id>@formal_in:0`), else `<id>@<local>`.
- **Determinism:** collect then sort; never emit during parallel work; two runs byte-identical.
- **stdout carries only JSON**; logs to stderr; partial resolution exits 0.
- **k-limiting:** `--graph-field-depth` (default 3) bounds every access path and the summary label sets — mandatory for the fixpoint's termination.
- Spotless is auto-applied by the build; run `./gradlew spotlessApply` before each commit.
- Commit messages: conventional commits, no attribution footers of any kind.

**Interfaces:**
- Consumes: `Map<String, JModule>` after L3 (body populated, `callee` backfilled by L2), `JCallable.getParameters()`, `JBodyNode` call nodes (`getCallee()`, `getArgumentExpr()`, `getReturnType()`).
- Produces:

```java
public final class SdgVertices {
    public static final class Result {
        public final List<JIdEdge> paramIn;   // global ordinals, sorted (src,dst)
        public final List<JIdEdge> paramOut;  // global ordinals, sorted (src,dst)
    }
    /** Mutates modules in place (adds synthetic body nodes); returns the application-scope edges. */
    public static Result apply(Map<String, JModule> modules);
}
```

Vertex rules (keystone-exact):
- Per callable with ≥1 parameter: `@formal_in:<i>` (`kind:"formal_in"`, `of:<param name>`), one per parameter, in declaration order.
- Per callable with non-void, non-constructor return: `@formal_out` (`kind:"formal_out"`, `of:"$ret"`).
- Per body `call` node with **non-null in-project** `callee` (id does not contain `"/@external/"`): `<call-local>/actual_in:<i>` (`kind:"actual_in"`, `of:"arg"+i`, `parent:<call-local>`) for each of the call's `argumentExpr` entries; `<call-local>/actual_out` (`kind:"actual_out"`, `of:"$ret"`, `parent`) when the call's `returnType` is present and not `"void"`.
- Edges: `param_in` `actual_in:i → callee@formal_in:i` for `i < min(nArgs, nCalleeParams)` (varargs: args beyond the last formal all map to the last `formal_in`); `param_out` `callee@formal_out → actual_out` when both vertices exist. Callee parameter count resolved by locating the callee callable through a `can://`-id index built over `modules` — an in-project callee that cannot be found (stale id) contributes vertices but **no edge** (edge-only-when-resolved).
- No synthetic vertex for external callees (no body to connect to) — documented, matches keystone.

import com.ibm.cldk.schema.JBodyNode;
import com.ibm.cldk.schema.JCallable;
import com.ibm.cldk.schema.JIdEdge;
import com.ibm.cldk.schema.JModule;

import java.util.Comparator;

import java.util.List;
import java.util.Map;

/**
 * L4 stage 7 (HRB assembly), derived: the synthetic parameter vertices and the cross-function
 * param_in/param_out edges are structurally determined by the L2-backfilled call sites and the
 * callee's parameter list, so they are built directly from the v2 tree — no engine, pure and
 * deterministic. Summary edges are the SummaryPass's job (PR 2), and the semantic ddg is
 * L4WalaOverlays' (points-to genuinely needs WALA).
 */
public final class SdgVertices {

    private SdgVertices() {}

    public static final class Result {
        public final List<JIdEdge> paramIn;
        public final List<JIdEdge> paramOut;

        Result(List<JIdEdge> paramIn, List<JIdEdge> paramOut) {
            this.paramIn = paramIn;
            this.paramOut = paramOut;
        }
    }

    public static Result apply(Map<String, JModule> modules) {
        Map<String, JCallable> byId = new LinkedHashMap<>();
        forEachCallable(modules, c -> {
            if (c.getId() != null) {
                byId.put(c.getId(), c);
            }
        });

        List<JIdEdge> paramIn = new ArrayList<>();
        List<JIdEdge> paramOut = new ArrayList<>();
        forEachCallable(modules, c -> {
            addFormals(c);
            addActualsAndEdges(c, byId, paramIn, paramOut);
        });

        paramIn.sort(Comparator.comparing(JIdEdge::getSrc).thenComparing(JIdEdge::getDst));
        paramOut.sort(Comparator.comparing(JIdEdge::getSrc).thenComparing(JIdEdge::getDst));
        return new Result(paramIn, paramOut);
    }
    // addFormals: for i, p in c.getParameters(): body.put("@formal_in:" + i, vertex("formal_in", p.getName(), null));
    //   if returnsValue(c): body.put("@formal_out", vertex("formal_out", "$ret", null));
    //   returnsValue(c) = c.getReturnType() != null && !"void".equals(c.getReturnType()) && !"constructor".equals(c.getKind())
    // addActualsAndEdges: for (local, node) in a snapshot copy of c.getBody() where kind=="call"
    //   && callee != null && !callee.contains("/@external/"):
    //   for i < node.getArgumentExpr().size(): body.put(local + "/actual_in:" + i, vertex("actual_in", "arg" + i, local));
    //   if node.getReturnType() != null && !"void".equals(node.getReturnType()): body.put(local + "/actual_out", vertex("actual_out", "$ret", local));
    //   JCallable callee = byId.get(node.getCallee()); if callee == null → vertices only, no edges;
    //   for i < min(nArgs, max(1, calleeParams)): paramIn.add(edge(global(c, local + "/actual_in:" + i),
    //       global(callee, "@formal_in:" + Math.min(i, calleeParams - 1))));   // varargs collapse
    //   if callee has @formal_out and caller has local + "/actual_out": paramOut.add(edge(global(callee, "@formal_out"), global(c, local + "/actual_out")));
    // global(c, local) = local.startsWith("@") ? c.getId() + local : c.getId() + "@" + local;  // ordinal rule
    // vertex(kind, of, parent): new JBodyNode, setKind/setOf/setParent — no span (synthetics carry none).
    // forEachCallable: the recursive walk (modules → types → callables → local types), java.util.function.Consumer<JCallable>.
}

### Task 9: `SummaryPass` — bottom-up k-limited fixpoint → `summary` edges

**Files:**
- Create: `src/main/java/com/ibm/cldk/syntactic_analysis/dataflow/SummaryPass.java`
- Test: `src/test/java/com/ibm/cldk/syntactic_analysis/dataflow/SummaryPassTest.java`

**Interfaces:**
- Consumes: `Map<String, JModule>` post-Task-6 (`body` with synthetic vertices, `ddg` with ssa+points-to edges, `cfg`), `List<JCallEdge>` call graph, `Scc.condense`, `int fieldDepth` (bounds label sets).
- Produces: `public static void apply(Map<String, JModule> modules, List<JCallEdge> callGraph, int fieldDepth)` — sets `callable.setSummary(List<JIdEdge>)` (local-id endpoints `<call-local>/actual_in:i → <call-local>/actual_out`, sorted `(src,dst)`) on every callable that has at least one such flow; leaves `summary` null elsewhere.

**Algorithm:**

1. **Per-callable transfer relation** `flows(c) ⊆ params(c) × {$ret}`: parameter `i` flows to the return.
   - Build a directed reachability graph over `c`'s body-node ids: an edge per `ddg` entry (`src→dst`, any `var`); plus, per call site with a known callee summary, a bridge `<call>/actual_in:j → <call>/actual_out` for each `(j→$ret)` in the callee's current summary set.
   - Seeds for parameter `i`: every ddg edge whose `var`'s base segment (text before the first `.`/`[`) equals the parameter's name — take that edge's `src` node. Also seed the call-site `actual_in:j` vertex when the call node's `argumentExpr.get(j)` contains the parameter name as a word (`\b<name>\b` regex) — the syntactic argument binding.
   - Sinks: any body node with `kind == "return"`, and the callable's `@formal_out` vertex.
   - `flows(c)` contains `i` iff BFS from `i`'s seeds reaches a sink.
2. **Bottom-up over `Scc.condense`:** process components callees-first. Within a multi-node SCC, iterate all members' step-1 computation until no member's `flows` set changes (monotone: sets only grow; bounded by arity — terminates). k-limiting: access-path vars longer than `fieldDepth` segments are treated as their k-prefix when matching bases (matches `AccessPath.of`'s collapse).
3. **Emission:** for every caller call site whose callee has `(j→$ret) ∈ flows(callee)` and both `<call>/actual_in:j` and `<call>/actual_out` vertices exist: add `JIdEdge(<call-local>/actual_in:j, <call-local>/actual_out)` to the **caller's** `summary`.
